\begin{abstract}
We design and implement a new linear code for the Zip$^+$ PCS that uses
an additive Reed--Solomon FFT over $\GF(2^{32}) = \F_2[X]/f$ as its
underlying structure, but applies that algorithm \emph{structurally
in the lifted integer ring} $\Z[X]/\flift$, where $\flift$ is the
$\Z$-polynomial with the same coefficients as $f$. The construction
is the binary-field analogue of the IPRS code already shipped in
Zinc$^+$, which lifts a multiplicative Reed--Solomon NTT over
$\F_{65537}$ to a pseudo-NTT over $\Z$. We describe the algorithm,
the Rust implementation, the open protocol-integration gap, and the
optimization journey that took the per-commit cost from a baseline of
$\sim 6$\,s down to $\sim 232$\,ms on Apple M4 with rayon parallelism
and a tightly-sized native coefficient type.
\end{abstract}
